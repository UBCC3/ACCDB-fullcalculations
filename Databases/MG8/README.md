# MG8

The MG8 dataset from Chan B. Formulation of Small Test Sets Using Large Test Sets for Efficient Assessment of Quantum Chemistry Methods. J Chem Theory Comput. 2018 Aug 14;14(8):4254-4262. doi: [10.1021/acs.jctc.8b00514](https://doi.org/10.1021/acs.jctc.8b00514). Epub 2018 Jul 13. PMID: 30004698.

The datapoint rows were extracted directly from the MGCDB84 DatasetEval.csv file (provided with the original ACCDB).
